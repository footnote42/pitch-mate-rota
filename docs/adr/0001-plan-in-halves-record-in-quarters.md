# Plan in halves, record in quarters, plan stays primary

Coaches plan festival selection in halves, but real games see substitutions mid-half, so what was actually played is recorded separately as a match record in quarters. The plan is the primary artifact: the match record never edits it. It is shown alongside the plan (planned vs played per player) and feeds auto-fill for the games still to come, so shortfalls get made up on the fly.

## Considered Options

- **Plan in quarters too**: rejected. Doubles the grid and does not match how coaches think before kick-off.
- **Record overwrites the plan**: rejected. Loses the intent the coach set out with, and a pitchside mis-tap would silently corrupt the plan.
