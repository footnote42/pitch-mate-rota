# About Squad Rotation Tool

## The Problem

As a U10 rugby coach, managing player rotations during festival games was consistently challenging. Using pen-and-paper grids made it difficult to:

- Ensure compliance with RFU "half game" rules (every player must get at least 50% playing time)
- Balance experienced vs novice players across different halves
- Track fairness in real-time across multiple games
- Make quick adjustments for injuries or late arrivals
- Share the rota with co-coaches and parents

## The Solution

Squad Rotation Tool is a mobile-first web application that digitizes the rotation planning process. It provides:

- Visual grid interface matching the familiar paper system
- Automatic fairness tracking and validation
- Real-time team balance indicators
- Persistent storage between sessions
- Mobile-optimized for pitchside use

## Development Approach

### Why This Project?

This project serves dual purposes:
1. **Practical utility**: Solve a real coaching problem I face regularly
2. **Learning journey**: Develop programming skills through a meaningful, self-directed project

### Why Lovable?

Rather than hand-coding from scratch, I chose Lovable (an AI-powered app builder) because:
- Faster time-to-working-prototype for a hobbyist developer
- Generates production-quality React/TypeScript code
- Allows iteration through natural language instructions
- Provides immediate visual feedback
- Reduces barrier to entry while still offering learning opportunities

### Why GitHub?

Using GitHub for version control provides:
- Safe experimentation (can always revert changes)
- Backup and recovery
- Collaboration potential with other coaches
- Documentation and decision tracking
- Professional development practices

### Anticipated End State

**Phase 1 (MVP)** - Current state:
- Fixed configuration (13 players, 8 on field, 5 games)
- Binary experience levels
- Manual assignment of players to halves
- Basic fairness and balance tracking

**Phase 2** - Near-term enhancements:
- Configurable squad sizes and game counts
- Multi-level experience ratings
- Festival history and archiving
- Enhanced sharing capabilities

**Phase 3** - Long-term vision:
- Master squad database across season
- Detailed player skill profiles
- Club branding and personalization
- Advanced analytics and reporting
